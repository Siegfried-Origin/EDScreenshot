Capture the Galaxy in True HDR

A screenshot tool for Elite Dangerous. Bypass baked-in post-processing and capture raw rendering data for ultimate control in post-production.

Download Latest Release View Source

Raw Pipeline Access

Captures images directly from the rendering pipeline, preserving high dynamic range data before tone mapping.

Pro Formats

Save your captures in OpenEXR or 32-bit TIFF for use in Lightroom, GIMP, or Affinity Photo.

EDHM Compatible

Seamlessly integrates with EDHM by replacing the d3d11.dll, allowing you to use both tools simultaneously.

Quick Start Guide

1

Install EDHM

This tool is designed to work alongside the EDHM-UI.
Download EDHM-UI.

2

Download the Tool

Grab the latest installer or ZIP from the GitHub releases page.
Download ED Screenshot.

3

Run & Capture

Launch the game and press F12 to take your first HDR shot.

Pro Tip

For the highest possible resolution, increase your Supersampling to 1.0 or higher in the game's Graphics Quality settings.

Output path:
%USERPROFILE%\Pictures\ED Screenshot
